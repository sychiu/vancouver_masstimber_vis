# Project selection

The projects featured in this map were identified through two public inventories of mass-timber construction:

- [Naturally Wood projects](https://www.naturallywood.com/projects/)
- [Natural Resources Canada’s State of Mass Timber in Canada dataset](https://open.canada.ca/data/en/dataset/9d00aa0a-a825-4804-b29b-1eff4f82a085)

The map features 11 mass-timber projects across Metro Vancouver.

Project locations and building geometries were downloaded from OpenStreetMap using Overpass Turbo.
